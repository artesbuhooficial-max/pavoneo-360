Cómo usar esta guía

Drive no permite que una web externa salte automáticamente a un segundo concreto. Utiliza el minuto indicado en el reproductor para localizar cada bloque.

  1. Elige la idea que necesitas.
  2. Mueve la barra al minuto señalado.
  3. Apunta una acción antes de continuar.
Qué te llevas

Tres ideas para aplicar al terminar

01Diseña una narrativa

Ordena el lanzamiento como una secuencia que despierta curiosidad, explica y mantiene el interés.

02Da una función a cada pieza

Cada publicación debe preparar, revelar, demostrar o recordar; si no cumple una función, sobra.

03Sostén la conversación

El lanzamiento no termina el día de publicación: reutiliza señales, respuestas y resultados para darle continuidad.

Esta guía se ha elaborado a partir de la transcripción con marcas de tiempo del vídeo original. Los capítulos condensan las ideas de Román para facilitar el visionado; no sustituyen la sesión completa.
