Hoja de Ruta

Centraliza la información imprescindible de cada concierto o evento para que artista, músicos y equipo técnico trabajen con la misma versión.

Cómo utilizarla

  1. Duplica una hoja para cada evento exportándola como JSON.
  2. Completa primero datos generales, contactos y horarios.
  3. Revisa logística, técnica, condiciones y materiales 48 horas antes.
  4. Imprime o guarda como PDF y compártela solo con el equipo implicado.

Los datos se guardan únicamente en este navegador. No incluyas documentación fiscal innecesaria al compartirla.
